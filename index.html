Read-first · Odoo AI Bridge · v0.1.0

Asisten Lokalmart untuk membaca Odoo.

App ini menjadi jembatan aman antara Odoo Lokalmart dan AI. Ia tidak membuat, mengubah, atau menghapus record. Tugasnya membaca struktur, mengekspor konteks, dan membuat audit awal agar file bisa kamu kirim ke ChatGPT.

1. ScanBaca model dan field Odoo, termasuk custom x_.
2. ExportBuat context JSON untuk dianalisis Asisten Lokalmart.
3. AuditTemukan data kosong, duplikat barcode, dan risiko struktur.

Koneksi

Credential Odoo disimpan di Environment Variables Vercel. UI hanya butuh token admin bridge.

Belum ada request.

Aksi Bridge

Pilih aksi yang kamu butuhkan. Untuk dikirim ke ChatGPT, yang paling penting adalah Context Export dan Audit.

Output JSON

Download hasilnya lalu upload ke ChatGPT agar Asisten Lokalmart bisa membaca kondisi Odoo.

Catatan keamanan: jangan sebarkan token, jangan memakai token di query URL publik, dan gunakan API key Odoo khusus integrasi dengan hak akses seperlunya.
